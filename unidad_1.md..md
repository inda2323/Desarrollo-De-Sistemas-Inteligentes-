act 1.2 casos de uso de zabbix
- **Monitoreo de servidores**
    - Zabbix supervisa servidores Windows o Linux.
    - Controla CPU, memoria RAM, almacenamiento y procesos.
    - Puede enviar una alerta cuando algún recurso supera un límite.
- **Monitoreo de redes**
    - Se utiliza para supervisar routers, switches y puntos de acceso.
    - Permite revisar tráfico, disponibilidad, pérdida de paquetes y ancho de banda.
    - Si un dispositivo deja de responder, Zabbix genera una alerta.
- **Monitoreo de bases de datos**
    - Permite supervisar bases de datos como MySQL, PostgreSQL u Oracle.
    - Se pueden controlar conexiones, consultas, rendimiento y espacio utilizado.
    - Ayuda a detectar problemas antes de que afecten a los usuarios.
- **Monitoreo de aplicaciones y servicios web**
    - Zabbix puede comprobar si una página web o aplicación está disponible.
    - Puede medir tiempos de respuesta y detectar errores.
    - Si un servicio deja de funcionar, puede notificar al administrador.
- **Monitoreo de infraestructura empresarial**
    - Se puede implementar para supervisar toda una empresa: servidores, redes, máquinas virtuales, aplicaciones y servicios.
    - Los administradores pueden visualizar el estado de la infraestructura desde un solo panel.
    - También permite generar gráficas, reportes y alertas para prevenir fallas.
